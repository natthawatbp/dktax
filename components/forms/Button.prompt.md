Bootstrap button themed Guardian Blue; use for every action (login, save, export, pay, LINE notify).
```jsx
<Button icon="fas fa-sign-in-alt" size="lg" block>เข้าสู่ระบบ</Button>
<Button variant="outline" icon="fas fa-sync-alt">รีเฟรช</Button>
<Button variant="line" icon="fab fa-line">แจ้งเตือนผ่าน LINE OA</Button>
```
Variants: primary, outline, secondary, danger, success, line, ghost. `loading` swaps icon for spinner with copy like "กำลังบันทึกข้อมูล...".
